# Input To SVG [V0.0.6]
** Godot 4.7.1 ** 
I needed a way to dynamicly display controls 
In another project, I needed a way for a dynamic and simple way to display inputs according to the controller (PS4, GameCube, Xbox, etc.). The goal is to get SVG files as output.
I hope to use it for:
- Configuring controls
- In texts and tutorials, such as “press A to…”
